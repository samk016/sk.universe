# Sameer Khan — Personal Website

A responsive personal website about cloud computing, astronomy, and astrophysics.

## Files

- `index.html` — website content and page structure
- `style.css` — visual design and responsive styling
- `script.js` — highlights the navigation link for the section currently in view
- `README.md` — project and publishing instructions

## Preview locally

Open `index.html` in a web browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create a GitHub repository (or open the repository where you want the website).
2. Upload these four files to the **root** of the repository, keeping their filenames unchanged.
3. Commit the files to your repository's default branch (usually `main`).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

If your repository is named `username.github.io`, GitHub Pages can publish it at that root domain. For a regular project repository, the URL usually includes the repository name.
